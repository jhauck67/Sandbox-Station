JSON Stringify

Un petit utilitaire bien pratique, tout en finesse technique.

✅ Terminé

Stack Technique

À propos du projet

Ce projet est un petit utilitaire développé pour automatiser la conversion de n'importe quel bloc de texte ou de code brut en une chaîne de caractères JSON valide (aussi appelée stringified JSON ).

L'objectif principal était d'explorer les capacités modernes du JavaScript :
1. Maîtriser la méthode `JSON.stringify()` pour la sérialisation des données.
2. Utiliser l' API `navigator.clipboard` pour le copier-coller du résultat en un seul clic, une fonctionnalité essentielle pour une bonne UX.
J'ai également veillé à appliquer une architecture CSS modulaire basée sur des variables sémantiques (approche Design System ) pour garantir une maintenance facile et un design responsive soigné.

Fonctionnalités clés

  • ✔️ Sérialisation JSON : Conversion rapide et fiable de l'entrée texte en une chaîne de caractères JSON utilisable.
  • ✔️ Copie en un clic : Intégration de l'API moderne `navigator.clipboard` pour copier le résultat dans le presse-papiers de l'utilisateur avec un *feedback* visuel clair.
  • ✔️ Architecture CSS modulaire : Styles structurés et facilement maintenables grâce à l'utilisation intensive de Variables CSS natives pour les couleurs et les espacements.

Aspects techniques

Architecture

Le projet repose sur une structure HTML sémantique minimaliste, des styles CSS en Variables CSS natives (pas de préprocesseur) pour garantir un Design System léger, et un JavaScript pur (Vanilla JS) pour toute la logique fonctionnelle.
J'ai privilégié une approche de programmation claire, en isolant les sélecteurs et les listeners, ce qui a permis d'encapsuler la logique de conversion et de copie efficacement.

Défis techniques

Le principal défi a été la gestion de l' asynchrone lié à l'API du presse-papiers (via `navigator.clipboard.writeText()`). Contrairement à une fonction synchrone, cet appel est une Promesse , dont le résultat n'est pas immédiat.
Cela m'a permis d'apprendre à mettre en place une gestion claire du *feedback* utilisateur pour cette opération non bloquante :
🔹 Problème : Comment informer l'utilisateur de la réussite sans bloquer l'interface ?
🔹 Solution : Utiliser les méthodes `.then()` et `.catch()` de la Promesse pour modifier temporairement le texte du bouton (ex: "Copié !"), puis le réinitialiser avec un `setTimeout()`. Une excellente introduction à la gestion des opérations asynchrones en JavaScript !
